## Selected Work

### Smart Acoustical Eye

Wearable assistive AI for visually impaired users, funded by the **IGNITE NGIRI 2022–23 research grant**.

- Led development as Project Lead and delivered a functional prototype
- Combined real-time multi-object detection with audio-guided environmental awareness
- Built offline OCR and text-to-speech capabilities for reading surrounding text without internet access
- Supported operation in both lit and dark conditions with sub-second response time

### FootballVision

Automated football-match analysis using custom-trained **YOLOv5** models for player, ball, and referee detection. The pipeline includes:

- Player tracking
- K-Means team assignment
- Optical-flow camera-motion compensation
- Possession tracking
- CLI and Streamlit interfaces

### Other Projects

- **Snow-Road Slipperiness Detection:** Real-time YOLOv8 segmentation with slippery-level classification
- **Driver Drowsiness Detection:** Deep-learning alertness monitoring deployed on Raspberry Pi
- **HaptiCare:** VR-based haptic-jacket therapy system for rotator-cuff shoulder rehabilitation
